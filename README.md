# livinai.app

Public website for Livinai, served by GitHub Pages at https://livinai.app

| Path | Page |
|---|---|
| `/` | Home (the Livinai app) |
| `/business/` | Livinai for Business |
| `/business/try/`, `/business/c/` | Embeddable business tools (not indexed) |
| `/support/` | Support |
| `/privacy/` | Privacy policy |
| `/404.html` | Not found |

Shared design system: `assets/site.css` and `assets/site.js`. Icons come from the app icon (`assets/images/icon-square.png` in the app repo).
